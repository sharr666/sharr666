Earlier monograph drafts referenced 234 entries; the canonical public release is the 563-block corpus on Hugging Face.
- **Intentional Gap (Option C, Author Decision — Nov 12, 2026):** Blocks `#0146–#0148` between Daftar 17 (Latin, ending at `#0145`) and Daftar 18 (Ancient Greek, starting at `#0149`) are preserved as intentional silence (`status = "INTENTIONAL_GAP"`). See `GAP_C_DECISION.md` in the Hugging Face dataset.
- **Intended Use:** Exploratory test concept for **defensive-only** research on Non-BMP tokenization robustness, prompt-injection resistance, and semiotic deconstruction.
